## 2. SEO Programmatic Strategy (The Engine)

We have 10,600 unique name pages. This is our biggest asset. We will treat each name as a standalone SEO landing page.

### 2.1. URL & Structure Architecture
*   **URL Pattern:** `namingguru.in/name/[slug]` (e.g., `/name/arun`, `/name/kavya`)
*   **Canonical Tags:** Self-referencing to avoid duplicate content issues from filters.
*   **H1:** `[Name] Meaning, Numerology & Nakshatra Guide`
*   **H2s:**
    *   Meaning & Origin (Tamil/English)
    *   Numerology Score (Pythagorean & Chaldean)
    *   Best Nakshatra & Rashi

    *   Similar Names / Alternatives

## 4. Social Automation & Virality Loop

### 4.1. The "Poll Share" Virality Loop
*   **Mechanism:**
    1.  Parent creates a shortlist of 3-5 names in NamingGuru.
    2.  Clicks "Share Poll" -> Generates a unique link: `namingguru.in/poll/[id]`.
    3.  Parent shares link on WhatsApp Family Group.
    4.  Relatives click link -> See names -> Vote for their favorite.
    5.  **Viral Hook:** When a relative votes, they see: *"You voted for [Name]! Create your own name shortlist for free at NamingGuru."*
    6.  **Result:** Relative becomes a new user.
*   **Automation:**
    *   **Backend:** `POST /api/polls` creates poll, returns shareable link.
    *   **Frontend:** Poll page is a lightweight, mobile-optimized React component.
    *   **Analytics:** Track `poll_shares` and `poll_voters` as key KPIs.

### 4.2. Instagram Reels & YouTube Shorts (Automated)
*   **Content Type:** "Name Meaning in 15 Seconds."
*   **Format:**
    *   Visual: Name in Tamil script + English.
    *   Audio: TTS (Text-to-Speech) voice saying: "Arun means Light. Numerology 5. Best for Rohini Nakshatra."
    *   CTA: "Check your baby's name at NamingGuru.in."
*   **Automation Stack:**
    *   **Tool:** n8n (Self-hosted or Cloud Free Tier).
    *   **Trigger:** Weekly cron job.
    *   **Steps:**
        1.  Fetch 3 "Name of the Week" entries.
        2.  Generate TTS audio using free TTS API (e.g., Edge TTS or free tier of ElevenLabs if available, otherwise pre-recorded templates).
        3.  Generate video using `ffmpeg` (overlay text on background image).
        4.  Upload to YouTube Shorts/Instagram Reels via API (or manual upload if API limits are strict, but prepare assets automatically).
        5.  Post to WhatsApp Channel.
