# NamingGuru Feature Proposals: The Tamil Family Perspective

As a product designer deeply embedded in the Tamil cultural context, I view naming not just as a transaction, but as a **ritual of identity**. In Tamil households, the name is the first "gift" given to the child, and it carries the weight of family history, astrological destiny, and social standing.

The current MVP covers the *technical* aspects (numerology, nakshatra, meaning). However, it misses the **emotional and social friction points** that cause families to abandon apps or choose names they later regret. Below are 25 features designed to solve these specific pain points, structured for the NamingGuru team.

---

## 1. Social & Family Dynamics (The "Who is Saying Yes?")

### 1.1. The "Elders’ Approval" Mode (Big Font & Voice)
*   **Problem:** Grandparents (Aachi/Chetti) often struggle with small text, complex filters, and English interfaces. They need to verify the name feels "right" and see the meaning clearly.
*   **User Story:** "As a grandmother, I want a simple screen with large Tamil text and a button to hear the name pronounced, so I can give my blessing without struggling with the phone."
*   **MVP Scope:** A dedicated `/share/elders/[id]` route. No filters. Just the name, large meaning, audio play button, and a simple "I Approve" / "I Have Concerns" button that sends a notification to the parent.
*   **Effort:** S
*   **Impact:** 5
*   **Data Needed:** Existing name data, TTS audio (or pre-recorded for top 500), simple user role flag.

### 1.2. Couple Shortlist Voting (The "Us vs. Them" Resolver)
*   **Problem:** Husbands and wives often have different preferences (e.g., Dad wants traditional, Mom wants modern). This causes friction.
*   **User Story:** "As a couple, we want to see each other’s shortlists side-by-side and vote on a final top 3, so we can stop arguing and agree on a name."
*   **MVP Scope:** A "Partner Link" feature. Parent A shares a link; Parent B logs in (or uses guest mode) to view the shortlist and toggle "Like/Dislike" on each name. A shared dashboard shows the consensus.
*   **Effort:** M
*   **Impact:** 4
*   **Data Needed:** Shortlist table, user session management, simple voting schema.

### 1.3. Family Tree Conflict Checker
*   **Problem:** In Tamil culture, naming a child after a deceased elder is a sign of respect, but naming them after a *living* elder or a sibling who passed away can be taboo or confusing. Conversely, some families *want* to honor a specific ancestor.
*   **User Story:** "As a parent, I want to input my immediate family’s names to ensure I am not accidentally choosing a name that clashes with a living uncle or aunt, or to see if a name honors a specific grandparent."
*   **MVP Scope:** A "Family Context" input field on the shortlist page. Users can add 3-5 names. The system flags if the chosen name matches or sounds too similar to these names.
*   **Effort:** S
*   **Impact:** 3
*   **Data Needed:** User-provided family names (stored locally or in user profile), fuzzy matching algorithm.

### 1.4. Sibling Harmony & Rhyme Check
*   **Problem:** Parents often want names that "sound good together" (e.g., same starting letter, similar syllable count) or want to avoid names that rhyme awkwardly (e.g., "Karthik" and "Karthikeya" is fine, but "Ravi" and "Ravindra" might feel redundant).
*   **User Story:** "As a parent of a first child, I want to see how a potential second child’s name flows with my first child’s name, so the siblings sound like a set."
*   **MVP Scope:** On the name detail page, a "Sibling Preview" section. User inputs existing sibling name. System calculates: Syllable match, Starting letter match, and "Rhyme Risk" (ending phoneme similarity).
*   **Effort:** M
*   **Impact:** 4
*   **Data Needed:** Existing sibling name, phonetic analysis of the new name.

### 1.5. The "Regret Protection" Nickname Teaser
*   **Problem:** A name might mean "Lion" but sounds like a word that gets teased in school (e.g., a name that sounds like a negative slang term in English or Tamil).
*   **User Story:** "As a parent, I want to know if my child’s name has any obvious, negative, or awkward nicknames that kids might use to bully them, so I can avoid social embarrassment."
*   **MVP Scope:** A "Nickname Risk" score on the 7D scorecard. Uses a curated list of common Tamil/English slang and teasing patterns. Displays potential nicknames (both positive and negative).
*   **Effort:** M
*   **Impact:** 5
*   **Data Needed:** Curated list of slang/nicknames, phonetic similarity engine.

## 2. Practical & Administrative (The "Paperwork" Reality)

### 1.6. Document Spelling Checker (Aadhaar/Passport/School)
*   **Problem:** Tamil names in English script are often misspelled on official documents (e.g., "Kumar" vs "Kumarr", "Sri" vs "Shri"). This causes lifelong administrative headaches.
*   **User Story:** "As a parent, I want to see the most common *correct* English spellings for this Tamil name and warnings about common misspellings, so my child’s documents are consistent."
*   **MVP Scope:** On the name detail page, a "Document Fit" section. Shows: 1) Standard IAST/Transliteration, 2) Common Misspellings (red flag), 3) "Passport Safe" badge (if the name is short and unambiguous).
*   **Effort:** S
*   **Impact:** 5
*   **Data Needed:** Curated list of common misspellings per name, character count analysis.

### 1.7. Surname & Initial Combination Preview

*   **User Story:** "As a parent, I want to type in my surname and see the full name preview, including the initials, to ensure the combination looks professional and doesn’t spell an unintended word."
*   **MVP Scope:** A "Full Name Builder" widget. User inputs Surname. System displays: Full Name, Initials, and a "Initials Check" (e.g., if initials spell a negative word, flag it).
*   **Effort:** S
*   **Impact:** 4
*   **Data Needed:** User input surname, string manipulation logic.

### 1.8. Handwriting & Calligraphy Preview
*   **Problem:** Tamil script is beautiful. Parents want to see how the name looks in a traditional font, especially for the Namakaranam ceremony or birth certificate.
*   **User Story:** "As a parent, I want to see the name written in a beautiful Tamil calligraphy font, so I can visualize it on the baby’s shawl or birth certificate."
*   **MVP Scope:** A "Visual Preview" tab on the name detail page. Renders the name in 3 fonts: Standard Digital, Traditional Calligraphy, and Modern Sans-serif.
*   **Effort:** S
*   **Impact:** 3
*   **Data Needed:** Web fonts (TTF/WOFF2) for Tamil calligraphy.

### 1.9. Printable Naming Certificate (Namakaranam)
*   **Problem:** The Namakaranam ceremony is a big event. Families need a formal document to display or give to guests.
*   **User Story:** "As a parent, I want to download a beautifully designed PDF certificate with the baby’s name, meaning, and birth details, so I can frame it or share it with relatives."
*   **MVP Scope:** A "Generate Certificate" button on the shortlist. Creates a PDF with: Name (Tamil/English), Meaning, Nakshatra, Numerology Score, and a decorative border.

### 1.10. School Form & Form 6 Spelling Guide
*   **Problem:** When filling out school admission forms, parents are unsure whether to use the full Tamil name or the English transliteration.
*   **User Story:** "As a parent, I want a clear guide on how to write my child’s name in the 'Name in English' and 'Name in Mother Tongue' fields of standard Indian forms."
*   **MVP Scope:** A "Form Filling Guide" section on the name detail page. Shows: 1) How to write in English (standard transliteration), 2) How to write in Tamil (script), 3) Tips for specific fields (e.g., "Use 'S' not 'Sh' for this name").
*   **Effort:** S
*   **Impact:** 3
